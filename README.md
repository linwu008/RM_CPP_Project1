# RoboMaster 战术对抗模拟系统
RM比赛规则来源：[下载 RoboMaster 2027 比赛规则手册（中文版 V1.0.0）](https://bbs-web-static.robomaster.com/451e5737ba5d4463909a3013456a4e551792055647969/RoboMaster%202027%20%E6%9C%BA%E7%94%B2%E5%A4%A7%E5%B8%88%E8%B6%85%E7%BA%A7%E5%AF%B9%E6%8A%97%E8%B5%9B%E6%AF%94%E8%B5%9B%E8%A7%84%E5%88%99%E6%89%8B%E5%86%8CV1.0.0%EF%BC%8820261015%EF%BC%89.pdf)

项目必做依据相关要求，RM 官方手册用于参考和设计简化规则。

项目目标：使用C++独立设计并实现一个离线运行的回合制机器人对抗程序。以RM为背景，模拟两支战队从开赛、行动、裁决到结束的一次完整比赛。采用简化规则，不完全照搬官方赛规，不涉及硬件

## 初始数据检查

机器人、基地、前哨站初始坐标须位于地图范围内
同一阵营内机器人编号唯一，双方可以使用相同数字编号
机器人、前哨站、基地的初始生命值大于0
机器人的初始弹药和行动点大于或等于0
任一检查失败时，输出错误提示并结束程序
初始机器人之间，以及机器人与基地或前哨站坐标重合时，报告占位冲突

## 操作方式

模拟系统展示一次电脑自动算法基于RM简化规则下的模拟回合制对抗，对抗双方在一局规定的时间内在二维图形界面演示，观察者可以选择红蓝双方机器人，对选中机器人提交移动、攻击或补给行动；未选择的机器人则由算法进行自动操作和射击。C++ 根据当前状态检查并结算行动，界面及时显示位置、血量、弹药和行动结果。

双方不同种类的机器人通过“阵营＋队内编号”标识，与正式比赛编号规则一致

一局由多个回合组成，每回合具有一定的行动额度

## 地图规则

地图尺寸：28 列 × 15 行。每一个单位代表现实一米，支持小数
左上角原点坐标为 (0, 0)
x 向右增大，y 向下增大
合法范围：x为[0,28]，y为[0,15]
红方基地 (2, 7.5)、蓝方基地 (26, 7.5)，初始血量10000
前哨站：红( 11, 11.5 ); 蓝(17 , 3.5),初始血量1000


## 最小目标
v0.1版本目标是先构建一个的可视化的窗口显示简单地图和一个机器人，点击后能显示清楚的选中状态标记
